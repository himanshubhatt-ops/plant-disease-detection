🌱 Plant Disease Detection

A Deep Learning project that detects plant diseases from leaf images using image classification.

🛠️ Technologies Used

- Python
- TensorFlow / Keras
- CNN / Deep Learning
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

📌 Project Features

- Plant leaf image classification
- Disease prediction
- Prediction confidence score
- Model evaluation

🔄 Workflow

1. Data preprocessing
2. Image augmentation
3. Model training
4. Model evaluation
5. Disease prediction

📊 Result

The model predicts the disease category of a given plant leaf image along with its confidence score.

🚀 Future Improvements

- Improve model accuracy
- Add more plant disease classes
- Deploy as a web application
